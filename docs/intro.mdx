# Axon Documentation Portal

This site centralizes architecture references, schema documentation, and executable diagram definitions for Axon.

## Documentation scope

- Database schema and entity relationships
- Use case, activity, sequence, and state machine documentation
- Technical implementation references and conventions

## Diagram strategy

All diagrams are authored as Mermaid blocks directly in source-controlled markdown files.

| Artifact | Mermaid syntax |
| --- | --- |
| DB schema | erDiagram |
| Use case | flowchart |
| Activity | flowchart TD |
| Sequence | sequenceDiagram |
| State machines | stateDiagram-v2 |
