# Axon Documentation Portal

This site centralizes the Axon problem definition, architecture, system design, schema, diagrams, and reference materials.

## Documentation scope

- Problem definition and product overview
- System architecture and design artifacts
- Database schema and data contracts
- Use case and activity diagrams
- API contract and technical references

## Diagram strategy

All diagrams are authored as Mermaid blocks directly in source-controlled markdown files.

| Artifact | Mermaid syntax |
| --- | --- |
| DB schema | erDiagram |
| Use case | flowchart |
| Activity | flowchart TD |
| Sequence | sequenceDiagram |
| State machines | stateDiagram-v2 |
