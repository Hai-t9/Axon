# Tech Stack

## Baseline stack

- Web UI: React + TypeScript
- API service: Node.js + TypeScript (REST)
- Evaluation workers: Python + Docker runtime
- Database: PostgreSQL
- Cache: Redis
- Object storage: S3-compatible storage for datasets and model artifacts
- Observability: centralized logging and metrics
- CI/CD: GitHub Actions

## Notes

- Components are containerized for repeatable deployments.
- Swap parts of the stack as needed to match infrastructure constraints.
