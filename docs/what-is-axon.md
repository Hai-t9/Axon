# What is Axon

Axon is a web platform that manages model submission, evaluation, and leaderboard ranking for agricultural AI challenges.

## How to use Axon

1. Create or join a team.
2. Upload a model package (typically a Docker image or archive).
3. Select the target challenge phase and dataset.
4. Submit for evaluation and track job status.
5. Review scores, logs, and the leaderboard.

## Who uses it

- Teams submit models and monitor rankings.
- Evaluators manage datasets, metrics, and evaluation queues.
- Admins maintain phases, rules, and access control.
